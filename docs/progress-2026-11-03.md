## 一、项目是什么

一个 **agentic harness**，不是生成模型。目标：产出**可装配、可打印**的 3D 零件。

- **LLM 只输出结构化动作**（算子 + 目标 + 参数），不输出几何；
- 几何由生成器/参数化层执行；
- **证据只能由验证器产出**，修复必须有证据。

**四条不变量**：证据先于修复 · 预算是第一类对象（验证开销也记账）· 纯内核、状态由事实派生 · **未知 ≠ 通过**。

**两个平面**：数据平面（M0/M1，已冻结、只读）与 **v2 设计平面**（`DesignSpec` → 物化 → 验证 → 修复）。主线在设计平面。

### 2.4 过程中修掉的真实缺陷（不是润色）

1. 逐对 note 的键与判据不一致 → 三件跑出 `validated: full` 的**过度声明**；
2. 生成器 `marching_cubes` 返回索引空间 → 件被放大 80 倍的**微型装配体**；
3. 网格哈希在 STL float32 下**全部 19 件校验失败**；
4. **case memory 成功轮次从不落账** → 记忆策略完全失效（修后 `memory_hits=1`）；
5. 示例适配器 import 期自读 `.env` → 一次真实付费调用事故的机制被堵死。

## 三、还差什么

| # | 缺什么 | 阻塞点 / 原因 |
|---|---|---|
| 1 | **物理条件生成**（P3-1：失败区域掩码 / 局部 inpaint / 物理场作条件） | **前置条件不满足**：需要支持 mask/inpainting 的模型，当前商用 API 只接受整件文本提示。可先交付「协议 + 独立验收门 + 假模型测试」，但**不能宣称能改生成** |
| 2 | **真模型验证 LLM 反馈** | 本机无 key。上模型后要量两件事：**hint 命中率**、**suggestions 为空时是否 abstain** |
| 3 | **切片器真实闭环（C4）** | 本机没装 PrusaSlicer/OrcaSlicer → 「0.2 mm 壁被切片器拒绝」只验证了机制，未观测真机 |
| 4 | **统计主张** | holdout 只有 24 点、两个对照（LLM 策略未跑）、**无置信区间**。现在只能说「案例观察/效应量」，不能说「策略 A 优于 B」 |
| 5 | **resume 场景的记忆** | 旧轮次 provenance 未持久化，新进程只能记自己提议过的轮次 |
| 6 | **实物装配（第 6 层证据）** | 仍是 0：没有真机装过。仿真通过 ≠ 实物可装 |
| 7 | 口径细节 | `CLEARANCE_ERROR_FRACTION = 0.25` 是**约定值**；dovetail 2/8 更像行为空间问题而非策略能力 |

## 四、核心诉求现在到哪一步

> 「agent 在物理仿真环境里不断检测、反复修改 DiT 生成」

准确表述是三段：

1. **参数层闭环**：✅ 已实现——检测 → 结构化动作 → 修复 → 再检测，预算与证据齐全；
2. **生成器的文本通道**：✅ 已打通——hint-only 修复真的重生成，不再被判几何循环；
3. **物理条件指导生成**：❌ **未实现**——现在能说「做厚一点」，不能说「**这里**、**厚 0.4 mm**、**保持其余不变**」。这是 P3-1，也是课题最有价值的一块，前置是模型能力。
