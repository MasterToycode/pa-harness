## 2. 已完成项的技术要点

### P0-1 报告三态（`7685719`）

审计指出的三条「会说出比事实更强的话」的路径，逐条堵死：

1. **N 件路径跳过 `insert_material` 却不写 note** → `_PAIR_SKIPS` 一张表同时驱动「跳过」与「说明」，两者不再可能漂移；测试直接断言表内容与 note 前缀。
2. **被 sanity 禁用的验证器不计未评估** → `_run_registry` 对 `registry.disabled()` 也写 note（含禁用原因），`_did_not_run` 同时认裸 id 与 `<接口>/<验证器>` 两种键。
3. **环境证书先被过滤再算 `ok`** → `_verdicts` 现在把 `ok` 置 `None`、`unknown: true`、`validated: "unknown"`，并把证书列进 `environment_errors`。一份报告内部不再自相矛盾（顶层 `failed`、子字段 `true`）。

`verdict_text()` 成为三态转文字的唯一出口，`pah build` / `pah decompose` / `pah export` 共用。

### P0-2 导出闸门（`7685719`）

旧规则 `printable = not problems` 只看文件层（水密/体积/3MF），**不看 `validated` 与 `not_evaluated`**，于是「没声明打印朝向 → 悬垂没评估」的报告也能导出 `printable: true`。

新规则：任一主张可导出，当且仅当 `ok is true` **且** `validated == "full"` **且** `not_evaluated` 为空；文件层问题并入同一判据。

- 新增 `manifest.readiness.{printable,assembly_ready}`（含 `reasons/validated/not_evaluated/blocking`）、`wrote_files`、`report_sha256`，schema 升到 `pah-print-manifest/2`（`printable` 语义变严，必须算版本变更）。
- `--for-print`：**先判后写**。不满足则不写 STL/3MF/manifest 任何文件，退出码 3。
- 实测：`runs/decompose-three`（partial）退出 3、零文件；`runs/printable-cn`（full）退出 0、两件 + 3MF 正常。
